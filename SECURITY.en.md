# Security Policy

> Languages: [Português](./SECURITY.md) • [English](./SECURITY.en.md)

## Reporting a vulnerability

We take security seriously. If you discover a vulnerability (cross-site
scripting, DoS, secret leak, etc.) in this project, please:

1. **Do NOT** open a public issue describing the problem.
2. Send an email to `YOUR_EMAIL@example.com` with:
   - A clear description of the problem.
   - Reproduction steps (or a minimal proof of concept).
   - Estimated impact.
   - A mitigation suggestion, if any.

## Support policy

| Version | Support                                 |
|---------|-----------------------------------------|
| 0.1.x   | Critical security fixes only           |

Versions prior to 0.1 are not supported.

## Response time

- **Receipt acknowledgement**: within 48 hours.
- **Initial evaluation**: within 7 days.
- **Fix released**: target 30 days for critical, 90 days for medium.

## Coordinated disclosure

We notify the community via a GitHub Security Advisory after the fix is
released. We honor embargoes until then.
