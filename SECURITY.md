# Security Policy

> Languages: [Português](./SECURITY.md) • [English](./SECURITY.en.md)

## Reportando uma Vulnerabilidade

Levamos segurança a sério. Se você descobrir uma vulnerabilidade
(cross-site scripting, DoS, leak de secrets, etc.) neste projeto, por favor:

1. **NÃO** abra uma issue pública descrevendo o problema.
2. Envie um email para `YOUR_EMAIL@example.com` com:
   - Descrição clara do problema.
   - Passos de reprodução (ou prova de conceito minimal).
   - Impacto estimado.
   - Sugestão de mitigação, se houver.

## Política de Suporte

| Versão | Suporte                                |
|--------|----------------------------------------|
| 0.1.x  | Apenas correções de segurança críticas|

Versões anteriores a 0.1 não recebem suporte.

## Tempo de Resposta

- **Confirmação de recebimento**: até 48 horas.
- **Avaliação inicial**: até 7 dias.
- **Fix released**: prazo-alvo 30 dias para críticas, 90 dias para médias.

## Disclosure Coord

Avisamos a comunidade via GitHub Security Advisory após o fix ser
liberado em uma release. Respeitamos embargos até lá.
